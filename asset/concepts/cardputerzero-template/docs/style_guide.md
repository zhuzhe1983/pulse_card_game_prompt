# 《脉冲对决》卡面分层指南（模板重建稿）

上一轮整卡 AIGC 已被用户否定，尤其是风格 A 与 01–09 差距过大。本轮改为：**官方 SVG 固定层原样复用，AIGC 只画主体（char）**。旧的 `asset/concepts/cardputerzero/ 中的 v4` 已标记为 superseded。

未做验收声明：合成结果需人工 Read 后再判断。

## 母版

跨组底色本来就不同，不能假装 22 张共用一块底板。

| 风格 | 母版 | 底色路径填充 | 选取理由 |
| --- | --- | --- | --- |
| A（01–09） | `01_S3` | `#009ee0` | 该组最典型的 NFC 商品卡骨架 |
| B（10–22） | `10_CORE` | `#0079b4` | 该组第一张；标题与口号为原稿转曲，不是 18–22 的 Carlito 补字 |

每张卡 54×85 mm，导出 638×1004 px / 300 DPI。viewBox 为 `0 0 153.0708661417323 240.9448818897638`。圆角为官方 v2 的 `canonicalCardClip`，半径 3.18 mm 圆弧，不是重新发明的圆角。

选择方法来自官方 `char_extract/extract_chars.py` 的 `select_subject()`，不是“中间画一个大矩形就盖掉”。

## 可变层

1. **char**：新主体 PNG，以 `preserveAspectRatio` 嵌入官方 char 包围盒（A：`xMidYMid meet`；B：`xMidYMax meet`，让底部落在原阴影上）。
2. **动态名称**（仅 B）：`CARDPUTER ZERO`。原稿标题是转曲路径，未嵌入字体。现用本机 **Oswald variable（wght 700，轴最大值）** 转成字形路径，**同一路径黑色描边 + 白色填充**（不再用偏移的第二层 `<text>`），两行装进原 CORE 标题槽 `[42.207, 190.863, 110.863, 215.346]`，不覆盖黄胶囊。**不能声称与原 CORE 字形 100% 一致**；Oswald 是替代面，两行也不是源四字锁闭的描摹。固定层转曲字未改。

## 不可交给 AIGC 的清单

- 顶栏 `Tap to Build`、底部 `NTAG215 NFC Card` / `Powered by M5Stack`、白胶囊 M5STACK
- 左上 M5STACK 锁闭
- 黄字 `IDEAS FAST TRACKED` 及黑胶囊
- 底板颜色、圆角 clip、54×85 画板
- 风格 B 脚下椭圆阴影
- 任何攻防 / HP / 自撰中文游戏名替换（本轮按用户要求完全沿用原品牌与宣传语）

A 的科技贴纸边框属于 char 层，因此新主体必须自己画成扁平模切徽章，而不是一张 3D 产品渲染。
