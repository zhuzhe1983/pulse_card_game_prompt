# 设备牌与成长

设备基线为 content/clash_roster_96.json，共 96 张；当前数值在加载后应用 content/clash_balance.json.card_overrides。覆盖不改变 rid、官方型号、SKU、素材、成长链和装配兼容。

保留 9 条一星到二星的成长链，不把硬件 v1.1 / v1.2 当作星级，也不增加三星。原位升星支付差价，主控的原配件随升星进入墓地，产生新入场限制，不额外占主控位。剩余差异以 reference/clash.js 的 promote() 及测试为准。

48 张主控中 24 张带效果，具体费用、攻耐与入场效果由 JSON 覆盖层集中管理，禁止在文案、图鉴和引擎分别维护不同数字。硬件与游戏角色的区分仍保留在原基线数据里。
