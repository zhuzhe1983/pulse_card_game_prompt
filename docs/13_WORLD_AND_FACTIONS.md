# 13 · 脉冲对决：现在能玩什么

中文名「脉冲对决」，英文显示名 PULSE。这一章给读规则的人。协议、存档和验收仍在后面的章节，不在这里改。

一句话：现在能跑完的是基础 14 张牌，规则集 `pcg.core.v1`。后面的族群、冠、链和面甲是设计草案，没有放进 `content/core_pack.json`，参考裁判也不会执行它们。

## 一局在做什么

每人带 10 张牌，最多打 3 个小局。每小局最多打出 5 张，也可以停手。比的是场上的整数战力。打出去的牌这局不回来，没打的留到下一小局。没有生命值，也没有攻击条。

基础 14 张已经能打完这种局：12 个角色加「增益信号」「干扰信号」。教学牌组不用实体英雄卡，也不用任何扩展。

## 人看见的是族群

玩家只看见出身，不看见资源包、固件或接口手册。

| 出身 | 气质 | 基础包里已有的脸 |
| --- | --- | --- |
| 堆叠 | 城垛和将军 | 核心守卫、TOUGH · 护卫 |
| 细刃 | 窄刃和头顶的冠 | StickC · 通讯员 |
| 微核 | 小信使，脚下只有一个座位 | ATOM · 侦察兵、ATOM Matrix · 协作员 |
| 面甲 | 底盘是身子，面板是脸 | 还没有 |
| 链式 | 按顺序传递的一队 | 还没有 |
| 键使 | 一把键盘的史官 | Cardputer · 干扰员 |
| 印记 | 被外壳养成的人 | Dial · 调度员、Stamp · 哨兵、Echo · 扩音手 |
| 墨面 | 慢一拍的书记 | PaperMono · 档案官 |
| 屏界 | 视野宽，口却少 | 还没有 |
| 工坊 | 另一套律法的主事 | 还没有 |
| 织网 | 很小的结网者 | LoRa · 中继手 |

公共库是谁都能带的器具和战术，不是第十二个出身。Unit 一类的东西放在这里。

卡面表达身份和收藏。草案卡不在图上写战力，正式基础卡的战力以卡包为准，不画进宣传卡。原卡两种面貌见第 16 章。第一轮生成试做已经放弃；固定模板的重制还没进入仓库。

## 草案若启用，配对怎么说

现实里接得上，游戏里才有资格结成配对。没查到，就各自计自己的战力，不写成克制。官方点名合不上的结构，不能结成那一档配对，也不扣基础战力，更不写烧毁。

每张牌仍只占 1 次出牌，随从和器具都算进 10 张牌和 5 次出牌。没有免费贴装。

数字都是未实测的建议。完整方案、例牌和取舍在 [14_EXPANSION_DRAFT.md](14_EXPANSION_DRAFT.md)。
