# 当前视觉与交互

采用电子工作台位图 UI：蓝灰防静电垫、白色 ABS 模块外壳、拉丝铝、PCB 铜走线和少量青色/琥珀 LED。主体是 ESP/M5 开发板与电子模块；炉石只作玩法参考，禁止套用原木酒馆、羊皮纸和中世纪装饰。早期原木概念已弃用。

内置 ImageGen 已生成 6 个界面组件（台面、手牌框、战场框、核心、按钮、卡背）和 12 张技能插画。技能表现电弧、停机、修复、超频、数据读取、编程等电子动作，是游戏演绎，不冒充产品照片或功能说明。费用、卡名、技能句、攻耐由代码绘制；真实设备主体图保留。完整提示词和映射见 [视觉资源清单](../content/clash_visual_assets.json)，素材规范见 web 的 [位图 UI](../../pulse_card_game_web/docs/RASTER_UI_V1.md)。

战场主控接近平放，保留轻微层次但去掉大角度透视。技能效果常驻在手牌上，不依赖悬停。战场、核心、手牌和结束回合分别占有区域。手机手牌独立横滚，低高度横屏使用右侧双列手牌，场上 7 台单位可滚动选择。主体字号和命中区域按设备尺寸调整，目标牌和按钮不能互相遮挡。

菜单收纳模式、调试演练、NFC 与重开。操作错误在当前场面解释，不扣资源。动画不应延迟玩家判断；遵循 prefers-reduced-motion。结算页给出结果与重开入口。手牌交接需遮挡，确认后当前玩家移到下方。

具体实现为 web 的 src/clash/raster.css、src/clash/tactical.css；素材在 src/clash/scene/raster-v1/，source/ 保存 PNG 原稿，网页只加载 WebP。截图在 output/playwright/。硬件原卡美术规范仍见第 16 章，不把游戏数值画进官方宣传原图。
