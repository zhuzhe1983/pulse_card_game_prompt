# 族群扩展计划（玩家看出身，作者看分包）

研究日期：2026-11-10（Asia/Shanghai）  
目标：以后客户端若跑在 ESP32 上，不要一次把所有卡图和全部文案装进内存；但玩家面对的是「新的族群来到脉冲对决」，不是商店货架上的 DLC 清单，更不是固件分区说明。

## 1. 玩家信息架构

玩家只看到：

- 这是哪一个族群的英雄；
- 他们常用什么样的随从与器具；
- 公共库里有谁都能用的工具和战术。

玩家不要看到：资源包 ID、按系列拆包、热更新清单、防止一次加载太多之类的句子。那些留给作者和后续集成工作流。

每次扩展在故事里就是「又一个族群接通了脉冲」。这和硬件上 Stick / Faces / Chain 本来就是不同生态的事实吻合，而不需要把接口名字念给玩家听。

## 2. 作者分包（一次只装入选定族群 + 公共库去重）

| 资源包（作者用语） | 玩家感知 | 里面放什么 | 不要放什么 |
| --- | --- | --- | --- |
| 基础包 | 完整可玩的脉冲对决 | 堆叠族核心英雄（Basic/Gray/Fire/M5GO/Core2/CoreS3/SE/Tough）、初代与 Core2 底盘、通用 Unit、通用战术、星轨模块、热瞳镜等公共工具 | 不要把所有 HAT/Chain/Faces 塞进来 |
| 细刃包 | 细刃族到来 | Stick 各代英雄、经典 HAT 随从、StickS3 专属映窗、与官方禁配相关的结构牌 | 不要复制一份气候瓶；引用公共库 |
| 微核包 | 微核族到来 | Atom 英雄、Atomic 底座、转接桥 | Chain 节点仍放在链式包，桥只提供跨族资格 |
| 链式包 | 链式族到来 | DualKey、节点、八腕·链环、寻址回环 | 不要再做一张 Atom 英雄 |
| 面甲包 | 面甲族到来 | Bottom3 与三块面板 | 不要再做 Core2/CoreS3 英雄 |
| 键使包 | 键使族到来 | Cardputer 及其 Adv/Mesh 皮肤或衍生，不重复基础 Unit | Cap CC1101 等 Adv 专属可作本包装备 |
| 印记包 | 印记族到来 | Dial、Capsule、DinMeter、Air Quality、StamPLC、裸 Stamp 若需要 | 不要把已经做成 Cardputer 的 Stamp-S3 再当第二英雄 |
| 墨面包 | 墨面族到来 | Paper 各 SKU 的差异做成少数英雄+异画，不要每个屏幕驱动一版强度 | 不要默认塞入 Core 堆叠模块 |
| 屏界包 | 屏界族到来 | Tab5、CoreMatrix、Tab5 键盘 | Module 仍尽量引用基础包公共模块 |
| 工坊包 | 工坊族到来 | CoreMP135、CM4Stack、Station、PowerHub | 明确它们不是「更强的付费 Core」 |
| 织网包 | 织网族到来 | NanoC6/H2、Thread 叙事 | 体量小，可并入屏界或工坊，但不要拆出付费强度档 |

基础包必须自成一局：10 张牌、三小局、有英雄、有公共装备、有反制战术，不购买任何扩展也能完整体会「留不留一手」。

## 3. 去重与加载（用游戏资源语言说）

- **一台英雄只出现在一个包。** CoreS3 只住在基础包（或明确的堆叠核心），Face 包只引用「任何堆叠族英雄」标签，不复制都督卡图。
- **共享 Unit 进公共库。** 气候瓶、测距钉、分路匣、识别环只画一次。扩展包若需要展示它们，调用同一张卡图与同一段规则文本。
- **跨族桥单独标注，但不双收英雄。** 转接桥在微核包；它让微核英雄获得「临时链主」资格。链式包的节点检查的是资格标签，不关心英雄来自哪个包。
- **同一设备的修订号优先做异画而不是新强度。** Core2 v1.1 / v1.3、PaperMono / Lite、Atom-Matrix v1.1，默认同一张英雄的版本差，只有玩法确实不同（例如 SE 砍掉相机）才拆卡。
- **按选定族群加载：** 开一局时只需加载基础公共库 + 本局允许的族群卡图与技能文本。未选中的细刃冠、链式节点、面甲面板可以不读入。这是「这一桌请了哪些客人」，不是「下载了哪个付费 DLC」。

## 4. 扩展不卖强度

分包是为了叙事分族和资源分批，不是为了让后买的包更会赢。

- 基础包英雄的战力带宽（设计值大约 4–7）与扩展包英雄（大约 3–8）重叠，不出现「扩展英雄基础战力默认 +3」。
- 扩展带来的是新的**配合方式**（冠位、链路顺序、换脸、单 Grove 瓶颈），同时带来对应的反制（结构干涉、寻址回环、过载示警已在基础包）。
- 任何「必须买齐所有族群才能拿到最强无限加成」的设计都应视为错误。跨族桥有明确 +1 上限。
- 非 ESP32 宿主（Tab5 的 P4、CoreMP135、CM4Stack、ToughC5）用气质和限制区分，不写成付费更强进化体。

## 5. 建议的制作顺序

1. 先把基础包 10 人桌（堆叠族 + 公共库 + 2～3 张新战术）与现有 12+2 对名、去重。
2. 细刃包：HAT 代差和 StickS3 三条官方结构禁配，最能教会玩家「不是同族就能加成」。
3. 链式包：顺序寻址是独特机制，和现有比总战力不冲突。
4. 面甲包：底盘 + 一块面板就是完整故事，三块面板靠地址冲突自我平衡。
5. 微核包提供跨族桥，应在链式包之后或同时，避免桥没有节点可接。
6. 其余包按美术量插入；墨面与屏界更适合用卡图而不是新数值体系取胜。

这样既方便以后按族群分批读入卡图，又不会把脉冲对决讲成一套工程发行说明。
