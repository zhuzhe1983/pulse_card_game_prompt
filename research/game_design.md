# 脉冲对决卡牌设计草案（基于 M5Stack 产品事实）

研究日期：2026-11-10（Asia/Shanghai）  
英文名：PULSE 中文名：脉冲对决 协议标识：pulse-card / pcg（不变）  
视觉：黑白电子漫画，设备拟人。  
数值状态：**全部为未实测设计值**，不是平衡实测，也不是现有 12 英雄 + 2 战术的替代清单。它们是在现有主规则上向外生长的草稿，给后续云端工作流写入 `pulse_card_game_prompt` 使用。

卡表：`card_candidates.csv`（74 张有区别的草案）

## 1. 主规则对齐（不要改成 HP 对战）

沿用现有骨架：

- 每位玩家构建/持有 **10 张牌**，最多打 **3 个小局**。
- 每小局最多打出 **5 张**，可以 PASS。
- 比较本小局的 **整数总战力**。
- 打出的牌本场不回收。

因此卡面主数值是：

- **基础战力**（正整数，打出即计入）
- **行动占用**（默认 1，少数一体机英雄为 2，计入「每局最多 5 张」）
- **技能与触发限制**（写明每回合一次 / 每局限一次 / 强制优先）
- **兼容标签**（决定能否形成羁绊，不决定「这张牌能不能被放进套牌」）

不把「攻击 / 生命」写进主卡面。需要耐久条的想法见文末隔离附录。

## 3. 角色分工（在建议上的发挥）

- **英雄**：独立可编程宿主。Core 像将军，Stick/Atom 像游侠与信使，Tab5/Paper 像视野型人物。一台宿主只做一张英雄，不把 CoreS3 同时写进多个包。
- **随从**：强绑定配件。HAT、Faces 面板、Chain 节点、Atomic 底座、M5GO 底盘。板上的 STM32 只是随从的「内府管家」，不是第二英雄。
- **装备**：更通用的 Unit 与可换脚的堆叠模块。同一功能的 I2C / GPIO / UART / Chain 版本做成不同武器，而不是同一张牌的皮肤。
- **战术**：把「拨码、分路、代差、结构警告、磁扰、电源预算、留牌」变成可见选择，而不是后台修正。

边界处理：

- Unit Thermal2、CardKB2：默认装备。Thermal2 有一条「场上无英雄时可独立计分」的铭文，对应官方「也可独立使用」，仍不能再招募随从。
- TimerCamera / UnitV2：本轮未做成卡，以免和现有英雄名单撞车；若后续要加，应是「侦察英雄」而非堆叠将军。
- Module LLM 的 AX630C、Tab5 的 C6、Thread BR 的 H2：伴随者，不是第二英雄。

## 4. 计分顺序、上限、循环

建议结算顺序（写死，避免循环）：

1. 统计本回合打出的牌的基础战力与行动占用是否合法（占用合计不超过 5）。
2. 结算强制效果：结构干涉、地址冲突、Fire PSRAM 暗伤、磁扰。这些效果**取消或施加惩罚**，不创造新的配对。
3. 结算配对加成，每对牌每回合最多一次，且必须标签合法。
4. 结算战术牌，但战术只能修改步骤 3 的结果一次，不能再次触发步骤 3。
5. 应用回合加成上限后锁定总分。

加成上限（设计草案）：

- 单张牌提供的配对加成最多 +2。
- 一名玩家每小局来自「兼容配对」的总加成最多 +3。
- 链式加成：每条链路最多 +2（双钥的左右是两条链路）。
- 跨族桥（Atom+ToChain+节点）最多 +1，且计入 +3 总上限。
- 「过载示警」在兑现 3 次及以上配件加成后砍掉最后一次，用来惩罚无上限幻想。

硬件接得上 ≠ 无限叠 buff。接得上只表示允许进入步骤 3 的资格审查。

## 5. 附属卡与 10 / 5 的关系（明确结论）

**推荐默认（也是本表数值所假设的规则）：**

- 随从和装备都是普通卡，计入 **10 张持牌**。
- 它们打出时计入 **5 张出牌上限**（行动占用为 1，除非另写）。
- 「绑定」只影响能否获得配对加成，不让一张牌免费贴在英雄身上。

这样规则对将来可能跑在 ESP32 上的客户端更干净：打出就是打出，没有隐藏的免费附加层。

可选的丰富规则（若以后要做，必须单独成篇，不要和默认表混用）：每小局一次，可将一张带 `attach` 的随从叠在本回合刚打出的合法英雄上，不额外消耗出牌位，但仍占用 10 张持牌。本草案**不采用**此规则。

## 6. 合法配对与反制举例

- 触屏执政官 + 二代箱底：+2。触屏执政官 + 普通底座：无加成且 -1（官方结构警告）。
- 焰核将军 + 初代 UART 定位羽：取消富内存并 -1（官方 GPIO16/17=PSRAM）。
- 三省都督 + 带磁叙事牌：「磁扰」或自带磁附件取消感知加成（官方 BMM150 注意）。
- 新律细刃 + 迷你摇杆冠：结构干涉 -1（官方 U156）。其它经典 HAT 对 StickS3 **不加也不断**（未知）。
- 面甲键士 + 面甲御手：地址冲突，取消面板加成（两者官方均为 I2C 0x08）。算士地址未知，不强制冲突。
- 链式双钥 + 两个节点分列左右：最多 +2，不会因为再接第三个节点指数增长。
- 气候瓶插在只有 UART 口的叙事上：无加成。回声锤与回声钉不能互替。
- 分路匣让本将因地址冲突失效的第二件 I2C 器具恢复一次加成。

这些都是「资格与上限」，不是把不兼容说成更强的隐藏共鸣。

## 7. 与现有 12 英雄 + 2 战术的关系

现有名单本轮没有去仓库里核对具体名字（按任务不读仓库）。建议后续集成时：

- 保留原 12+2 作为基础包已认识的面孔；
- 本表中的入门城主 / 触屏执政官 / 细刃游侠 等若与旧名重复，应改用旧名或做成异画，不要并成两张强度不同的同一设备；
- 新战术「脉冲静默」有意呼应「留一手」的宣传语气，若旧战术已经表达同一件事，选一留一。

## 8. 隔离附录：不要放进主规则的 HP 备选

以下内容**不是**当前脉冲对决，只为避免以后有人把装备叙事误写成掉血战斗：

- 「结构损伤条」：仅在教学关里演示 Core2 硬叠 Base 会损坏设备。用 0/1 标记，不用攻防来回扣。
- 「供电耐久」：连续三小局都兑现 3 次以上配件加成则下局-1。这仍是资源压力，不是 HP 对打。
- 完整的攻击-生命自走棋模型与现有「10 牌、三小局、比总战力」冲突，若要做应另开模式名，不得覆盖 PULSE 主规则。

主设计停在整数战力、费用/行动占用、有上限的触发技能。
